🔒 刻意不放进本页的配置

  • SECRET_KEY / ADMIN_PASSWORD / DATABASE_URL / MCP_*_TOKEN —— 根信任。存进数据库 = 拿到数据面 （SQL 注入或备份文件）的人顺带获得伪造会话 / 改管理员密码的能力。
  • COOKIE_SECURE / CORS_ORIGIN / TRUSTED_PROXIES / SESSION_IDLE_MINUTES —— 每个请求都要判断，进数据库是 拿一次查询换一行配置。
  • ENABLED_PLUGINS —— 启动时加载，进数据库照样要重启才生效， 放这里只会给人「改了没用」的错觉。
