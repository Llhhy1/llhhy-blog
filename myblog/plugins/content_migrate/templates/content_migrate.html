📦 内容迁移（WordPress / Typecho → 本站）

支持两种输入：WordPress 的 WXR 导出（后台「工具 → 导出」）和 Typecho 的 SQL 备份（phpMyAdmin / 面板导出）。文件只在本次请求里解析， 不会留在服务器上；写入数据库的操作在后台任务中执行。

{{ csrf_input() }}





导入范围

  • 会导入：文章标题、正文、摘要、发布时间、分类（一篇文章只保留第一个分类）、标签、特色图。
  • 不会导入：页面（Page）、评论、用户与密码、附件库、主题/插件设置。评论建议在原站另行留档。
  • WordPress 正文是 HTML，Typecho 的 Markdown 按原样保存；前台渲染仍会经过本站的清洗链路。
  • 重复导入不会翻倍：保留 slug 时按 slug 去重；不保留时按「标题 + 创建时间」去重。
  • 导入期间不会触发「新文章」通知/SEO 推送/订阅邮件 —— 否则订阅者会被迁移文章刷屏。
